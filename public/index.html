Methodology & limitations

        

          
TradePro is a paper-trading demo built to show real quantitative engineering, not a production trading system. Every indicator (RSI, MACD, ADX, EMA, realized volatility, volume ratio) is computed from live daily OHLCV bars pulled from Yahoo Finance's public chart API - there is no mocked data path once this is deployed.

          
The confluence gate is a simple, explainable heuristic: it requires broad technical agreement (7 of 8 independent checks) before risking capital, which is intentionally conservative and will sit in cash for long stretches. Position sizing and stops are risk-based (ATR-derived), not fixed dollar amounts.

          
What this is not: a backtested-and-validated alpha strategy, a system with slippage/fee modeling, or anything connected to a real brokerage. All fills are simulated at the last traded price with zero slippage.
